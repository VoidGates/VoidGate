# Páginas do site

React. O idioma fica em `i18n.tsx` (português e inglês). `main.tsx` sobe a página. `App.tsx` junta as seções. O visual fica em `index.css`.

| Pasta | O que cuida |
| --- | --- |
| `components/` | Cada seção da página. |
| `detector/` | A demonstração no navegador. Não chama a API. |
| `assets/` | Logos. |
