## Como relatar

Abra um aviso privado em [Security advisories](https://github.com/VoidGates/VoidGate/security/advisories/new).

Não publique a chave, o corpo de uma mensagem real nem o conteúdo que a API devolveu. A decisão não deve repetir o texto enviado. Um relato que mostre esse eco está no escopo.

Uma issue pública serve para defeito sem dado secreto. O corpo de um erro e os campos `reason_codes` e `findings` são para o gateway, não para o cliente final.
