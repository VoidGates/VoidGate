# Documentação da API em execução

`openapi.json` é a especificação escrita à mão. `index.html` é o Swagger UI.

Os dois só são servidos com `VOIDGATE_DEV_DOCS=1`, bind em loopback e build de desenvolvimento. Uma rota nova precisa ser acrescentada aqui; o teste da crate confere os códigos de erro e as rotas que já estão na lista.
